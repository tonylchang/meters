About meters

meters

The system monitor you leave visible, on Mac, Windows, and Linux.

Activity Monitor, Task Manager, and btop are built for investigation; keeping them open costs screen space and attention. Menu bar and tray monitors squeeze into a narrow, crowded strip.

meters keeps the few metrics you care about in a small floating panel that stays on screen while you work. It floats above other windows, never takes keyboard focus, and stays grey until a reading deserves your attention.

MacWindowsLinuxNo network access

Status, Nov 2, 2026: The native Mac app's v1 is feature-complete and in daily use. Signed and notarized downloads are planned, with a notify-only update check. A Rust port, meters-rust, brings meters to Windows and Linux and also runs on Mac; see Platforms.

The panel in the corner is a live replica. Drag it to an edge or corner and it snaps into line; right-click it, or click the gauge in the menu bar, for its menu. Scroll the page: it stays where you put it.

Platforms

Mac, Windows, and Linux.

There are two builds. The native Swift app is the reference on Mac. tonylchang/meters-rust is a port of it, written in Rust with Slint, that runs on all three. It follows the same design, thresholds, and privacy rules, but feature parity is not complete.

PlatformWhere it stands
MacmetersFeature-complete v1 with all nine modules. Apple Silicon, macOS 26 or later, MIT License. Build it from source until signed downloads arrive.
Macmeters-rustAlso runs on a Mac, but reads only CPU, memory, and swap there so far; network, disk, GPU, battery, thermal, and free space are not wired up on Mac yet. The native app is the one to use there.
Windowsmeters-rustTopmost utility window and system tray. Built for Windows 10 and 11; tested natively on Windows Server 2022 so far.
Linuxmeters-rustGNOME, KDE Plasma, Xfce, and Cinnamon. X11 sessions work directly; GNOME uses a bundled Shell extension, and KDE on Wayland a bundled KWin script.

Readings depend on what each OS offers, and an unavailable one shows n/a, never an invented zero. Windows has no memory pressure or thermal state. Linux takes memory pressure from kernel PSI and thermal state from hardware trip points. GPU needs driver support, so common Intel setups on Linux show n/a.

meters-rust has no published releases or installers yet, and its repository is private for now.

Modules

Nine modules, each optional and reorderable.

The default is three rows: CPU, memory, and network. The panel's width and height follow the modules and forms you pick. These descriptions are for the Mac app; Platforms covers what differs elsewhere.

  • CPUTotal, or each core cluster your Mac reports, such as Super and Performance on M5 chips
  • MemoryMeasured as Activity Monitor measures it; highlighting follows memory pressure
  • GPUDevice utilization
  • NetworkDownload and upload; the one-row form names Wi-Fi
  • DiskRead and write, naming the physical disk, such as disk0
  • BatteryCharge, with an arrow for the direction it is actually moving
  • ThermalOK, Warm, Hot, or Critical
  • SwapSwap in use
  • Free spaceThe startup disk's available space, as Finder counts it

Settings has four tabs: General, Modules, Thresholds, and HUD. Readings every 0.5, 1, 2, or 5 seconds.

Thresholds

Quiet until interesting.

A row turns amber or red, with its value in semibold, only after 3 consecutive readings past a threshold, and returns to grey after 3 back under. If meters looks quiet, the machine is probably fine.

Privacy and performance

No network connections. Under 1% of one core.

On every platform, meters opens no network connections and has no analytics or crash reporting. It needs no administrator password or privileged helper, and no extra permission on a Mac; metric history stays in memory and is gone when you quit.
